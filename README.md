# 구미은혜로교회 홈페이지 설치 순서

이 폴더는 GitHub Pages(무료 호스팅) + 구글 시트/드라이브(게시판 저장) 구성입니다.

## 1. GitHub 저장소 만들기
1. github.com 에서 새 저장소를 만듭니다. 예: `guminunhye-church` (공개 저장소)
2. 이 폴더의 `index.html`, `images/church.png` 를 업로드합니다. (`apps-script/` 는 올리지 않아도 됩니다.)
3. 저장소 **Settings → Pages** 에서 Source 를 `main` 브랜치 `/ (root)` 로 지정하고 저장합니다.
4. 몇 분 뒤 주소가 나옵니다: `https://<아이디>.github.io/guminunhye-church/`

## 2. 구글 게시판 백엔드 만들기
1. script.google.com 에서 **새 프로젝트**를 만듭니다.
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
3. 함수 선택 목록에서 **setup** 을 고르고 **실행**합니다. 권한 허용을 요청하면 허용합니다.
   - 구글 드라이브에 `구미은혜로교회 게시판 데이터`(시트)와 `구미은혜로교회 첨부파일`(폴더)이 생깁니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL** 을 복사합니다.
5. `index.html` 을 열어 `API_URL` 값(`PASTE_APPS_SCRIPT_WEB_APP_URL_HERE`)을 복사한 URL로 바꾸고, 저장소에 다시 업로드합니다.

## 3. QR 코드
- 1번의 Pages 주소를 QR 코드로 만들어 주보, 현관, 문자 등에 붙이면 됩니다.

## 관리 방법
- **글 삭제**: 구글 시트 `posts` 탭에서 해당 행을 지우고, 첨부 파일이 있으면 드라이브 `구미은혜로교회 첨부파일` 폴더에서 같은 파일을 휴지통으로 보냅니다.
- **내용 수정**(예배 시간, 인사말 등): `index.html` 의 해당 문구를 고쳐 저장소에 다시 올립니다.
- 주의: 누구나 글을 쓸 수 있으므로 부적절한 글이 올라오면 위 방법으로 지워 주세요.
